# Customer_behaviour_analysis
Data Analytics Project showcasing customer behaviour analysis using Python, SQL and Power BI

**Overview**
This project demonstrates an end-to-end Data Analytics workflow using Python, SQL, and Power BI. The objective is to analyze customer shopping behaviour, uncover business insights, and present findings through an interactive dashboard and business report.
The project covers data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis, dashboard development, and presentation creation.
________________________________________

**Dataset**
The dataset contains customer shopping information, including:
•	Customer demographics
•	Product categories
•	Purchase amounts
•	Review ratings
•	Payment methods
•	Subscription status
•	Discount usage
•	Shipping preferences
The dataset is used to analyze customer behavior, sales trends, and purchasing patterns.

**Project Workflow**
1. Data Loading
   •	Imported dataset into Python using Pandas.
   •	Inspected dataset structure and data types.
2. Exploratory Data Analysis (EDA)
   •	Analyzed dataset dimensions and summary statistics.
   •	Identified trends and patterns.
   •	Explored customer purchasing behaviour.
3. Data Cleaning
   •	Checked for missing values.
   •	Removed duplicates.
   •	Corrected data inconsistencies.
   •	Prepared data for analysis.
4. SQL Analysis
   •	Loaded cleaned data into a relational database.
   •	Wrote SQL queries to answer business questions.
   •	Performed aggregations, filtering, ranking, and trend analysis.
Example analyses:
   •	Top-selling products
   •	Revenue by category
   •	Customer purchase behaviour
   •	Average review ratings
   •	Discount usage analysis
5. Power BI Dashboard
Created an interactive dashboard featuring:
   •	Total Revenue
   •	Total Orders
   •	Average Order Value
   •	Average Review Rating
   •	Revenue by Category
   •	Top Products
   •	Customer Segmentation
   •	Sales Trends
6. Reporting
   •	Summarized key findings.
   •	Documented methodology and insights.
   •	Created a business-focused analytics report.
7. Presentation
   •	Developed a presentation using Gamma AI.
   •	Highlighted objectives, methodology, dashboard visuals, and business recommendations.
