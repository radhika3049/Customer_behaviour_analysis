## 📌 Overview

This project demonstrates an **end-to-end Data Analytics workflow** using **Python, SQL, and Power BI** to analyze customer shopping behaviour and generate actionable business insights.

The project covers the complete analytics lifecycle, including:

* Data Loading
* Exploratory Data Analysis (EDA)
* Data Cleaning
* SQL-Based Business Analysis
* Interactive Dashboard Development
* Business Reporting
* Presentation Creation

The primary objective is to understand customer purchasing patterns, identify sales trends, and support data-driven decision-making through compelling visualizations and reports.

---

## 🎯 Project Objectives

* Analyze customer shopping behaviour.
* Identify top-performing products and categories.
* Understand customer spending patterns.
* Evaluate the impact of discounts and subscriptions.
* Measure customer satisfaction through review ratings.
* Present insights using an interactive Power BI dashboard.
